RELATIONSHIPS — Open Local Assistant (`local-ai-assistant` v1.0.0)
Machine-readable dependency edges for the Tauri 2 / Rust + React 19 codebase.

LEGEND
======
Format        subject | verb | object          (one edge per line)
Verbs         uses            a module reads/imports another, or consults it
              depends_on      a hard build- or runtime-order dependency
              emits           publishes a Tauri event (see the EVENTS section)
              subscribes_to   listens to a Tauri event
              calls           invokes a function or method
              implements      satisfies a trait / interface contract
              extends         adds members to a parent type or store
              produces        returns or yields a documented payload
              persists_to     writes rows, files or KV entries
              reads           loads rows, files or KV entries
              writes          creates or mutates rows, files or KV entries
Conventions   ::  separates module-path segments  (services::chat::orchestrator)
              /   is a filesystem path              (src/app/chatStore.ts)
              ::  a Rust type path, the same way   (ChatEvent::Done)
              *   "every member of"                (commands::*)
              -   the wire/serialised name of a struct field (settings.general.accent)
External      third-party systems are named by product (LM Studio, SearXNG,
              Hugging Face, GitHub, NVIDIA, DuckDuckGo, searx.space) and are
              not part of the crate graph.
