Open Local Assistant 1.2.0 — a smoother dictation and desktop experience. The dictation window now keeps track of the app you're speaking into, and the floating launcher stays aligned with your chat window.

Free and open source under the GPL-3.0 license. Everything still runs locally through LM Studio; nothing is sent anywhere unless you choose a hosted provider.

## Highlights
- **See where dictation will go:** the overlay shows the destination app and updates as you switch apps, including while reviewing your text
- **Review shortcuts work from anywhere:** insert with `Ctrl+Enter`, retry with `Ctrl+Shift+Enter`, or cancel with `Ctrl+Shift+Backspace`, even when another app has focus
- **A clearer destination label:** the app name is shown in a rounded, tapered tab; the destination prefix and app name are styled separately
- **The launcher follows your chat:** it stays aligned to the selected chat position, while custom positioning keeps the launcher draggable
- **More room for chat controls:** compact chat now opens wider and can be resized horizontally

## New since 1.1.0
- The dictation overlay tracks the foreground app and shows its friendly app name as the insertion destination
- Review remembers the destination and provides global insert, retry and cancel shortcuts
- The floating launcher aligns with chat position presets and has a soft circular glow; custom positioning remains draggable
- Compact chat defaults to 440×170 and can be resized horizontally from 440 to 760 pixels
- The destination tab and dictation overlay layout were refined for readability and visibility

## Downloads
- **Open-Local-Assistant-1.2.0-setup.exe**: installer (recommended)
- **Open-Local-Assistant-1.2.0-portable-win-x64.zip**: portable version, extract and run `Open Local Assistant.exe`

## Requirements
Windows 10/11 64-bit, plus one AI provider: LM Studio with its local server running, or an API key from OpenRouter, Google Gemini or Hugging Face.

## Windows SmartScreen
The builds are not code-signed, so Windows may show "Windows protected your PC". Click **More info → Run anyway**. To check a download, compare `Get-FileHash <file>` in PowerShell with the SHA-256 shown next to the file on this page.
