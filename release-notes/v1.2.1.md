Open Local Assistant 1.2.1 — clearer microphone troubleshooting and a verified Windows release build.

Free and open source under the GPL-3.0 license. Everything still runs locally through LM Studio; nothing is sent anywhere unless you choose a hosted provider.

## Highlights
- **More useful microphone errors:** when a capture stream fails to start, the chat window explains that microphone access can be enabled while a device or driver still fails to initialize.
- **Steps to troubleshoot:** the error points to Windows desktop-app microphone access and the selected input in Settings → Voice.
- **Technical details on demand:** expand the error to see the backend message, which can help identify the specific device or driver failure.

## New since 1.2.0
- Microphone startup errors include recovery guidance and expandable technical details.

## Downloads
- **Open-Local-Assistant-1.2.1-setup.exe**: installer (recommended)
- **Open-Local-Assistant-1.2.1-portable-win-x64.zip**: portable version, extract and run `Open Local Assistant.exe`
- **Open-Local-Assistant-1.2.1-SHA256SUMS.txt**: SHA-256 checksums for the installer and portable archive

## Requirements
Windows 10/11 64-bit, plus one AI provider: LM Studio with its local server running, or an API key from OpenRouter, Google Gemini or Hugging Face.

## Windows SmartScreen
The builds are not code-signed, so Windows may show "Windows protected your PC". Click **More info → Run anyway**. To check a download, compare `Get-FileHash <file>` in PowerShell with the SHA-256 in the checksum file.
