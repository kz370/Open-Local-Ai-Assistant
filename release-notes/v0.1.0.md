First release of Open Local Assistant, a free, private desktop AI assistant for Windows. It runs fully on your own PC through LM Studio, or on a hosted provider (OpenRouter, Google Gemini or Hugging Face), including their free models.

Free and open source under the GPL-3.0 license. This is an early release, so please report bugs in Issues.

## Highlights
- Choose your AI provider: LM Studio (fully local), or OpenRouter, Google Gemini or Hugging Face (free models available)
- Floating chat window (`Ctrl+Space`) with system tray support
- Voice in and out with local neural voices
- Hands-free call mode with live captions
- Dictation into any app (`Ctrl+Alt+Space`)
- English, Arabic (RTL) and German, all spoken by one small multilingual voice model (Supertonic 3, 31 languages)
- Right-click selected text in a reply to hear it aloud, or get an explanation in a pop-up or as the next message in the same chat
- Web search with sources
- MCP tool support, with confirmation before anything writes data or runs commands
- Optional NVIDIA GPU pack

## Downloads
- **Open-Local-Assistant-0.1.0-setup.exe**: installer (recommended)
- **Open-Local-Assistant-0.1.0-portable-win-x64.zip**: portable version, extract and run `Open Local Assistant.exe`

## Requirements
Windows 10/11 64-bit, plus one AI provider: LM Studio with its local server running, or an API key from OpenRouter, Google Gemini or Hugging Face.

## Windows SmartScreen
The builds are not code-signed yet, so Windows may show "Windows protected your PC". Click **More info → Run anyway**. To check a download, compare `Get-FileHash <file>` in PowerShell with the SHA-256 shown next to the file on this page.
