Open Local Assistant 1.1.0 — a dictation-focused release. Dictation now has **profiles**: write a title and a prompt once, pick the profile from the dictation window, and what you say comes out already shaped for that topic — code as a code block, an image description as an image prompt, notes as a clean list.

Free and open source under the GPL-3.0 license. Everything still runs locally through LM Studio; nothing is sent anywhere unless you choose a hosted provider.

## Highlights
- **Dictation profiles** (`Ctrl+Alt+Space` → the sliders pill): a named prompt added on top of the usual grammar correction, so a programming or imaging take no longer has to be retyped into shape
- **Profile editor** in Settings → Dictation → Manage profiles: unlimited entries, each with a title and a prompt, reorderable, with an explicit Save button
- **Searchable profile list** once you have 10 or more (you choose the threshold)
- **Dictation is now reliable on Windows**, the big one: it no longer drops, duplicates or scrambles characters

## Fixed
- **Dictation inserted garbled text on Windows.** Raw Unicode key injection lost and duplicated characters. Characters are now sent as real key events resolved against the target window's own keyboard layout, so they arrive byte-exact — including mixed case, digits, symbols and Arabic. Characters are spaced 16 ms apart, which is what the receiving applications actually need.
- **Dictation no longer accumulates stray characters mid-sentence.** A dropped keystroke used to desync the "what's on screen" model, so later words were diffed against fiction and left runs of junk behind; a word still being recognised is also no longer typed and then retyped.
- **Dictation failing to start with "the audio device could not be used".** Real cause was a driver buffer error a moment after the microphone opened. The capture thread now waits for the stream to settle and silently rebuilds it (up to four attempts) instead of failing the take. Later capture errors now surface instead of vanishing.
- **The dictation window's voice meter looked frozen.** It drew the average microphone level, which barely moves while you speak. It now draws the live spectrum, so every word shows up.
- **The dictation window's header no longer overflows** with a profile and a language pill side by side.

## New since 1.0.0
- Dictation profiles, and the profile picker in the dictation window
- Review before inserting: the result is held in an editable card so you can fix it and insert with `Ctrl+Enter`, instead of going straight into the app
- The overlay streams your words live while the transcript finalises, so you can start editing before it lands

## Requirements
Windows 10/11 64-bit, plus one AI provider: LM Studio with its local server running, or an API key from OpenRouter, Google Gemini or Hugging Face.

Profiles need a correction model: pick one under Settings → Dictation → Correct grammar and punctuation. Without one, a take still works — the raw transcript is inserted.

## Windows SmartScreen
The builds are not code-signed, so Windows may show "Windows protected your PC". Click **More info → Run anyway**. To check a download, compare `Get-FileHash <file>` in PowerShell with the SHA-256 shown next to the file on this page.
